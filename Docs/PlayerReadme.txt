허풍 경매장 (Bluff Auction) — 시험판
=====================================

내 물건의 진짜 가치는 나만 압니다. 시작가와 허풍 한마디로 비싸게 팔고,
남의 허풍은 꿰뚫어 싸게 사세요. 끝났을 때 [남은 돈 + 산 물건의 진짜 가치]가
가장 큰 사람이 이깁니다.


■ 실행
  1. 압축을 통째로 풉니다 (폴더 안의 파일을 빼내지 마세요).
  2. BluffAuction.exe 를 실행합니다.
  3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
     (아직 코드 서명을 하지 않은 시험판이라 뜨는 경고입니다.)
  4. 방화벽 허용을 물으면 [허용]을 누르세요. 친구와 온라인으로 할 때 필요합니다.

■ 사양
  Windows 10/11 64비트, DirectX 11 그래픽 카드, 메모리 4GB 이상
  마이크는 음성 채팅을 쓸 때만 필요합니다.

■ 조작 (게임 안 「게임 방법」에도 있어요)
  마우스          둘러보기 (Tab: 커서 모드 · 자세한 패널)
  Space · 패들 클릭  입찰          휠 · 1~4   올릴 금액
  Q W E · 도구 클릭  능력 (시세 비교 · 간이감정 · 거짓 통보)
  우클릭(누른 채)   가까이 보기     T  한마디
  Enter           채팅            M / V  마이크 켜기·끄기 / 누르고 말하기
  R(누른 채)       감정 표현 바퀴   F  탁자 위 물건·신문지 집기 / 내려놓기
  왼쪽 클릭        (들고 있을 때) 조준점 아래 사람에게 던지기 · 때리기
  Esc             일시정지 · 설정

■ 친구와 온라인 (3~8명, 빈자리는 AI)
  모두 같은 버전(이 압축 파일)을 써야 합니다.

  [Steam 친구]  포트 설정이 필요 없습니다.
    - 모두 Steam을 켜고 로그인한 채로 게임을 실행합니다.
    - 방장: 친구와 온라인 → 방 만들기 → 대기실의 「Steam 친구 초대」.
    - 친구: Steam 초대를 수락하거나, 온라인 화면의 「Steam 친구의 방」에서 참가.
    - 이 시험판은 아직 정식 Steam 앱 번호가 없어서 Valve의 시험 앱(Spacewar)으로
      연결됩니다. Steam 친구 목록에는 "Spacewar 플레이 중"으로 보입니다.
      (시험판에서 딴 업적은 Spacewar 쪽에 기록될 수 있습니다.)

  [같은 네트워크]  방장이 방을 만들면 친구 화면의 「같은 네트워크의 방」에 뜹니다.
  [인터넷 IP 접속]  방장 공유기에서 TCP 27615 포트를 열고, 친구가 방장의 주소를 입력합니다.

■ 저장 · 문제가 생기면
  저장 파일:  %USERPROFILE%\AppData\LocalLow\Hyeophap Games\Bluff Auction\save.json
  오류 기록:  같은 폴더의 Player.log 를 보내 주시면 고치는 데 큰 도움이 됩니다.

Bluff Auction — Playtest build
==============================

Only you know what your items are really worth. Sell high with a starting price
and a bluff, see through everyone else's, and buy low. Highest
[cash left + true value of what you bought] wins.

■ Running
  1. Extract the whole archive (keep all files together).
  2. Run BluffAuction.exe.
  3. If "Windows protected your PC" appears, click [More info] → [Run anyway]
     (this playtest build is not code-signed yet).
  4. Allow the firewall prompt if you want to play online.

■ Requirements
  Windows 10/11 64-bit, DirectX 11 GPU, 4 GB RAM. A microphone is optional (voice chat).

■ Controls (also under "How to Play" in game)
  Mouse  look around (Tab: cursor mode)     Space / click paddle  bid
  Wheel / 1–4  raise amount                 Q W E / click tools   abilities
  Hold RMB  lean in     T  quick line       Enter  chat
  M / V  mic toggle / push-to-talk          Hold R  emote wheel
  F  pick up / put down table props         LMB (holding)  throw or bonk whoever is under the crosshair
  Esc  pause / settings

■ Playing online (3–8 players, AI fills empty seats)
  Everyone must use the same build (this archive).
  [Steam friends] No port forwarding. Keep Steam running and logged in.
    Host: Play Online → Host a Room → "Invite Steam friends" in the lobby.
    Friends: accept the Steam invite or join from "Friends' rooms on Steam".
    This build has no Steam app ID yet and runs as Valve's test app "Spacewar";
    your friends list will show "Playing Spacewar".
  [LAN] Rooms on your network appear automatically.
  [Direct IP] The host forwards TCP port 27615; friends enter the host's address.

■ Saves & bug reports
  Save:  %USERPROFILE%\AppData\LocalLow\Hyeophap Games\Bluff Auction\save.json
  Log:   Player.log in the same folder — please attach it when reporting a bug.
